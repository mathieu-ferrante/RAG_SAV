**FR-700 — code E42 : contrôle complémentaire du relais K2 avant remplacement de la résistance de sole**

## Contexte

Sur le four FR-700, environ un tiers des remplacements de résistance de sole (pièce 62-1340) effectués suite à un code E42 n'ont pas résolu le défaut. Les retours d'ateliers montrent que le relais K2 de la carte de puissance, qui alimente la résistance de sole, est en cause dans ces situations.

## Nouvelle conduite à tenir

Pour tout code E42 sur FR-700, le technicien doit contrôler le relais K2 de la carte de puissance (mesure de continuité bobine et contacts) avant toute commande de résistance de sole. En cas de relais défectueux, remplacer la carte de puissance (pièce 62-2210). Côté conseiller niveau 1, la conduite client reste inchangée : planifier une intervention, les modes utilisant la sole étant indisponibles.

## Impact documentation

Cette vérification complémentaire ne figure ni dans le manuel du FR-700 ni dans le référentiel des codes erreur (version 2025-T4), qui seront mis à jour ultérieurement.

**Ce bulletin prévaut sur la documentation produit antérieure (manuels et référentiel des codes erreur) pour les points qu'il traite.**
