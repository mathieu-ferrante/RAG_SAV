**WX-500 — code E52 : défaut logiciel sur les appareils fabriqués à partir de mars 2025**

## Contexte

Une hausse des remplacements de sonde de température (pièce 44-3311) sans défaut confirmé a été constatée sur le lave-linge WX-500 depuis l'automne 2025. L'analyse du bureau d'études a identifié un défaut logiciel du module de commande affectant les appareils fabriqués à partir de mars 2025 (numéros de série commençant par 2503 et suivants) : une erreur de lecture transitoire de la sonde déclenche à tort le code E52.

## Nouvelle conduite à tenir

Pour tout code E52 sur WX-500, relever d'abord le numéro de série. S'il commence par 2503 ou un préfixe supérieur : faire installer la mise à jour firmware 4.2 via l'application Electrodomus Home (connexion Wi-Fi requise), puis faire relancer un cycle court. Dans plus de 90 % des cas constatés, le code ne réapparaît pas et aucun remplacement de sonde n'est nécessaire. Si le code persiste après mise à jour, ou si le numéro de série est antérieur à 2503 : appliquer la procédure habituelle (remplacement sonde CTN 44-3311).

## Impact documentation

Le manuel d'utilisation du WX-500 (chapitre Dépannage) indique uniquement le remplacement de la sonde et sera corrigé à la prochaine réédition. Le référentiel des codes erreur sera mis à jour dans sa version 2026-T1.

**Ce bulletin prévaut sur la documentation produit antérieure (manuels et référentiel des codes erreur) pour les points qu'il traite.**
